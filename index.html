Behind the page

Simple pieces, working together.

A small project can teach the whole deployment path, from a code change to a page served on the web.

⌘

GitHub Actions

A push to the main branch triggers the workflow that publishes this page.

◇

AWS OIDC

The workflow assumes an IAM role using temporary credentials instead of stored access keys.

☁

Amazon S3

The HTML file lives in a bucket configured to serve a static website.
